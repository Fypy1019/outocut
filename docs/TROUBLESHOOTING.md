# 故障排查

## 本地引擎未连接

- 在系统设置中刷新诊断日志。
- 确认安全软件未阻止 `outocut-engine.exe`。
- 开发环境确认 Python 依赖已安装，且 `python -m outocut_engine --help` 可运行。

## 素材扫描失败

- 确认目录仍存在且当前用户有读取权限。
- 中文路径受支持；损坏或无视频轨道文件会被标记而不会阻塞扫描。

## 抖音链接提取失败

- 提示“网络请求失败：ConnectError”且本机网络正常时，一般是系统代理已开启但代理软件未运行（例如代理节点切换、代理崩溃）。引擎已自动处理：优先按系统代理请求，连不上时自动回退直连，无需手动配置，不开代理、换节点或换电脑均可正常使用。
- 百炼转写模型可在“设置 → 文案配置设置 → 识别模型”中选择，下拉框只展示已实测、配置百炼 Key 即可直接使用的模型（paraformer-realtime-v2、paraformer-realtime-v1，WebSocket 实时识别，自带标点断句）。paraformer-v2/v1 等录音文件识别模型需要百炼 Key 具备 OSS 文件访问权限，暂未在界面展示（引擎已保留实现）。长音频会自动按 60 秒分片上传，单条视频时长不受限。
- 本地识别（离线）模式使用 paraformer-zh 中文识别模型（约 234MB）与标点断句模型（约 72MB），首次使用时在设置页点击“下载本地识别模型”即可，之后完全离线可用，识别结果会自动添加标点。
- 提示“视频音频下载失败”或“需要网页 Cookie”时，请在系统设置中粘贴抖音网页版 Cookie 后重试。
- “视频音频下载失败：已尝试 N 个播放地址均失败”多为抖音 CDN 偶发拦截/风控（同一链接上一次成功、下一次失败属正常现象）。引擎已内置多重容错：每个播放地址依次尝试 ffmpeg 直拉、httpx 下载+本地提取、移动/桌面 UA 轮换、HLS 播放列表支持、断流自动重下，并已在地址间加入短暂间隔；仍失败时建议稍等片刻重试，或粘贴 Cookie 后重试。彻底规避抖音风控无法 100% 保证，Cookie 加多次重试是当前最有效组合。

## AI或配音失败

- 检查 Key 所属区域、余额、模型权限和网络。
- 百炼返回非法JSON时可重试，或直接手工编辑镜头文案。
- MiniMax 复刻音频仅支持 WAV、MP3、M4A，大小不超过20MB，建议时长10秒至5分钟。

## NVENC失败

- 更新 NVIDIA 驱动并确认 FFmpeg 构建包含 `h264_nvenc`。
- OutoCut 会在片段编码失败时自动降级 CPU；也可在模板中直接选择 CPU H.264。

## 磁盘空间不足

- 合成需要片段中间文件，建议预留成片预计大小的3倍以上空间。
- 临时成片校验成功后才会移动到输出目录，避免留下伪成功文件。
