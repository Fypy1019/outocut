# OutoCut 使用手册

1. 首次打开后进入“系统设置”，配置默认成片目录。
2. 如需 AI 文案，填写阿里云百炼 API Key；如需配音或声音复刻，填写 MiniMax API Key。
3. 在“素材中心”创建分类，选择本地视频文件夹并重新扫描。HDR 素材会提示转换，损坏素材不会进入合成。
4. 在“镜头剪辑”选择素材分类，填写人设、参考文案和模板参数。
5. 点击“AI生成分镜”，也可以完全手工填写或修改每条镜头文案。
6. MiniMax 音色 ID 留空会生成无口播成片；填写后会先生成逐镜头配音。
7. 选择成片目录和批量数量，加入合成队列。
8. 在“任务中心”查看进度、取消、重试或打开成片。

每条成片会同时生成 `.ass` 字幕和 `.json` 任务清单。任务失败时，详情面板会显示可用于排查的 FFmpeg 或接口错误。
